通知设置
配置后，系统将在每次自动预约、手动预约或更新设置后，立即推送相关结果通知。
企业微信机器人配置步骤：
  1. 在企业微信群聊中，点击右上角 → 群机器人 → 添加机器人
  2. 复制机器人的Webhook地址
  3. 粘贴到上方输入框中
Telegram机器人配置步骤：
  1. 与 @BotFather 对话创建机器人，获取 TOKEN
  2. 获取你的 Chat ID（可通过 @userinfobot）
  3. 输入格式: https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<CHAT_ID>
飞书机器人配置步骤：
  1. 在飞书群聊中，点击群设置 → 群机器人 → 添加机器人
  2. 选择"自定义机器人"
  3. 复制机器人的Webhook地址
  4. 粘贴到上方输入框中
钉钉机器人配置步骤：
  1. 在钉钉群聊中，点击群设置 → 智能群助手 → 添加机器人
  2. 选择"自定义"机器人
  3. 安全设置选择"自定义关键词"，填写"预约"或"通知"
  4. 复制机器人的Webhook地址
  5. 粘贴到上方输入框中
