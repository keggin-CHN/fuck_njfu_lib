🚀 一键部署

图书馆实时流量和座位查询系统 - Cloudflare版

部署方式

🖥️ 本地脚本部署 推荐

使用自动化脚本一键完成部署

cd cloudflare
./deploy.sh

📦 Node.js部署

跨平台Node.js脚本，适合Windows用户

cd cloudflare
npm install
node deploy.js

🤖 GitHub Actions自动部署

推送代码自动部署，无需手动操作

1. 设置GitHub Secrets
2. 复制.github/workflows/deploy.yml
3. git push 触发部署

📝 手动部署

完全控制每个步骤的部署过程

cd cloudflare/worker
wrangler deploy
cd ../pages
wrangler pages deploy .
