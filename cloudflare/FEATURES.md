## 📊 核心功能（v1.0.0）

### 1. 实时流量监控

#### 功能描述
实时查询图书馆当前在馆人数和占用情况

#### 技术实现
- Worker抓取流量页面
- BeautifulSoup解析HTML
- 数据提取和计算
- 占用率可视化展示

#### API接口
```
GET /api/traffic
```

#### 前端展示
- 当前在馆人数
- 总容量
- 占用率百分比
- 进度条可视化
- 更新时间戳
- 一键刷新

### 2. 座位查询系统

#### 支持区域（12个）
- 二层：A区、B区
- 三层：A区、B区、C区、夹层
- 四层：A区、夹层
- 五层：A区
- 六层：A区
- 七层：北侧、南侧

#### 查询功能
- 按楼层筛选
- 按日期查询（今天/明天）
- 区域统计（总数/空闲/占用）
- 座位详情（每个座位的预约情况）
- 预约时间段显示

#### API接口
```
GET /api/seats/summary?days_offset=0
GET /api/seats/detail?area=区域名&days_offset=0
GET /api/areas
```

#### 前端展示
- 总览统计卡片
- 楼层筛选按钮
- 区域卡片展示
- 座位详情弹窗
- 预约信息列表

### 3. 认证系统

#### 双层认证
1. **CAS统一认证**
   - 获取登录表单
   - AES-256密码加密
   - 提交认证请求
   - 获取ticket

2. **图书馆系统认证**
   - 获取RSA公钥
   - RSA密码加密
   - 获取token和accNo
   - 验证认证状态

#### 安全措施
- 环境变量加密存储（Cloudflare Secrets）
- 密码不在代码中出现
- HTTPS全程加密传输
- 认证缓存（30分钟）
- 自动重新认证

### 4. 数据处理

#### Worker后端
- HTTP请求封装
- HTML解析
- JSON数据处理
- 错误处理和重试
- 日志记录

#### Pages前端
- Fetch API调用
- 数据渲染
- 用户交互
- 错误提示
- 加载状态
